# NewsFlowStream

A modern news aggregator built with Next.js, featuring a beautiful glass-morphism design and responsive layout.

## Features

- Beautiful glass-morphism design
- Responsive layout with mobile-first approach
- Infinite scroll for desktop view
- Mobile-friendly swipe interface
- Category-based news filtering
- Share functionality
- Loading animations and placeholders
- Ad placement support

## Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/newsflowstream.git
cd newsflowstream
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
